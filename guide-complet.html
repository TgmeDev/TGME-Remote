Installer et utiliser TGME Remote

Suivez ces étapes pour installer le serveur sur Synology, préparer les applications Windows et démarrer une première assistance.

Avant de commencer

  • Un NAS Synology avec DSM 7.2.2-72806 ou version ultérieure, et un modèle reconnu compatible par le Centre de paquets.
  • Un compte DSM autorisé à installer des paquets.
  • Les applications Windows Client et Technicien fournies par la console de votre NAS.

La page Téléchargement propose le paquet serveur et le présent guide. Si le Centre de paquets indique que le modèle n’est pas compatible, ne forcez pas l’installation.

1. Installer le serveur sur Synology

  1. Téléchargez le SPK depuis la page Téléchargement.
  2. Ouvrez le Centre de paquets dans DSM et choisissez l’installation manuelle.
  3. Sélectionnez le fichier SPK, puis suivez les étapes affichées par DSM et le paquet. Démarrez TGME Remote lorsque l’installation est terminée.
  4. Ouvrez la console TGME Remote à l’adresse de votre NAS fournie pour l’installation. Connectez-vous avec le compte admin. Après la mise à jour 0409, lisez et acceptez les conditions d’utilisation actualisées pour continuer, puis terminez la protection du compte si elle est demandée.

Le compte admin est réservé à l’administration et ne peut pas effectuer de prise en main. Sans licence, gardez ce compte et créez un compte Technicien distinct pour intervenir. Aucune fonction n’est désactivée et aucun quota commercial d’appareils n’est appliqué. La licence multi-Techniciens est permanente, sans expiration, et nécessaire uniquement pour autoriser plusieurs comptes Technicien.

Accès depuis Internet : ports à diriger vers le NAS

Si les postes Client ou Technicien se connectent depuis Internet, configurez sur le routeur une redirection vers l’adresse IP locale du NAS, avec les protocoles et ports ci-dessous :

  • TCP 5081 : accès HTTPS à la console et signalisation WSS des applications Windows.
  • TCP et UDP 3478 : STUN/TURN pour établir et relayer les sessions.
  • UDP 50000–51000 : médias des sessions qui passent par le relais.

Dans DSM, autorisez également ces services dans le pare-feu s’il est activé. Le paquet déclare les ports dans les outils DSM, mais ne garantit pas qu’une règle soit déjà active dans le routeur ou dans un profil de pare-feu existant.

Le port TCP 5080 est interne au NAS, entre le proxy HTTPS et le service. Ne le redirigez pas vers Internet. Si TGME Remote est utilisé uniquement sur le réseau local, aucune redirection Internet n’est nécessaire.

2. Préparer les comptes et les applications

  1. Dans la console, créez un compte Technicien pour la personne qui réalisera les interventions.
  2. Téléchargez depuis cette même console les applications TGME Remote Client et TGME Remote Technicien.
  3. Installez ou démarrez chaque application sur le PC correspondant. Utilisez les fichiers fournis par le NAS auquel ces postes doivent se connecter.

Le Client s’installe sur le poste qui recevra l’assistance. Le Technicien s’installe sur le poste de la personne qui intervient.

3. Installer et inscrire un Client

  1. Démarrez TGME Remote Client sur le PC à assister et suivez l’écran d’inscription.
  2. Pour un nouvel appareil, saisissez le jeton d’inscription fourni par l’administrateur du serveur.
  3. Une fois inscrit, le Client affiche son identifiant et un code temporaire. Communiquez-les uniquement au Technicien attendu, par un moyen de contact fiable.

Le jeton d’inscription sert uniquement à inscrire un nouveau Client et reste valable 30 jours. Après son expiration, il ne permet plus d’inscrire un nouvel appareil : demandez un jeton valide. Un Client déjà inscrit peut continuer à se reconnecter. Cette règle est indépendante de la licence.

4. Démarrer une assistance

Sur le poste Client

  1. Ouvrez TGME Remote Client et transmettez au Technicien l’identifiant du poste et le code temporaire affichés.
  2. Lorsqu’une demande apparaît, vérifiez que vous attendiez bien cette intervention et contrôlez le nom du Technicien.
  3. Acceptez la demande, puis comparez le code de sécurité affiché sur les deux postes avant de confirmer.

Sur le poste Technicien

  1. Ouvrez TGME Remote Technicien et connectez-vous avec votre compte Technicien.
  2. Recherchez le poste dans le carnet ou saisissez son identifiant. Entrez le code temporaire communiqué par le Client, puis choisissez Prendre le contrôle.
  3. Attendez l’accord du Client et confirmez que le code de sécurité correspond. La fenêtre du poste distant s’ouvre alors.
  4. À la fin de l’intervention, terminez la session depuis sa fenêtre.

Le Client garde la possibilité d’accepter ou de refuser une demande d’assistance accompagnée. N’acceptez une demande que si vous connaissez la personne qui intervient.

En cas de difficulté

  • Le paquet ne s’installe pas : vérifiez la compatibilité du modèle Synology et la version DSM requise dans le Centre de paquets.
  • Le poste n’apparaît pas : vérifiez que le Client a terminé son inscription et que le service TGME Remote fonctionne sur le NAS.
  • La demande n’aboutit pas : vérifiez que l’identifiant et le code temporaire correspondent au Client ouvert, puis recommencez avec l’accord de l’utilisateur.
  • Le jeton a expiré : demandez à l’administrateur du serveur un jeton valide pour chaque nouvelle inscription. Les Clients déjà inscrits n’ont pas à refaire leur inscription pour se reconnecter.

Pour retrouver les téléchargements, ouvrez la page TGME Remote. Pour une question sur votre installation, contactez l’administrateur de votre serveur.
