Utiliser les applications et gérer le serveur NAS

Les parcours essentiels du Client Windows, du Technicien et de l’administrateur Synology, réunis dans un guide autonome.

Ce tutoriel décrit la version 1.0.0-0409. Les codecs H.264, OpenH264 et AVC444 ne font plus partie des choix de cette version. Les noms des modes actuels sont TGME VP9, TGME VP8, Bureau hybride et TGME hybride.

1. Application Client

  1. Téléchargez le Client depuis la console TGME Remote du NAS. Choisissez la version portable ou installée selon le poste et les droits disponibles.
  2. Pour un nouvel ordinateur, entrez le jeton d’inscription donné par l’administrateur. Il sert à inscrire un nouveau Client et reste valable 30 jours ; un Client déjà inscrit peut continuer à se reconnecter après expiration.
  3. À l’ouverture, transmettez au Technicien attendu l’identifiant affiché par le Client. Pour une demande accompagnée, vérifiez le nom du Technicien et le code de sécurité puis acceptez uniquement l’intervention prévue.
  4. À la fin de l’assistance, fermez la session. La fenêtre Client se masque à la déconnexion du Technicien ; le service reste disponible pour les sessions suivantes.

2. Application Technicien

  1. Ouvrez l’application Technicien, connectez-vous avec votre compte, puis recherchez le poste dans le carnet partagé ou saisissez son identifiant.
  2. Vérifiez le poste visé et utilisez le code temporaire ou le mode d’accès autorisé. Pour une demande accompagnée, attendez l’accord du Client et comparez les codes de sécurité.
  3. Dans la fenêtre distante, choisissez l’écran, la résolution et l’échelle 100 % ou ajustée. Réglez clavier, son, presse-papiers et confidentialité selon les droits accordés. Ancrez les contrôles en haut, bas, gauche ou droite ; cliquez sur le raccourci pour retrouver la fenêtre. Terminez la session depuis sa fenêtre.
  4. Le carnet partagé peut être filtré selon les groupes visibles attribués au Technicien par l’administrateur.

Sans licence, le serveur permet un compte admin d’administration et un compte Technicien pour les prises en main. Le compte admin ne consomme pas la place Technicien et ne peut pas contrôler les postes.

3. Choisir l’affichage vidéo

TGME VP9

Mode vidéo pour privilégier une image fluide lorsque le contenu change souvent.

TGME VP8

Autre mode vidéo disponible, sélectionnable manuellement ou par choix automatique.

Bureau hybride

Mode hybride adapté aux changements d’écran mêlant contenu fixe et mouvement.

TGME hybride

Mode hybride fondé sur des tuiles avec une cadence élevée pour les scènes animées.

Le mode automatique s’appuie sur les audits des deux postes et les codecs réellement compatibles. Le menu permet aussi de choisir un mode manuellement. Le petit engrenage persistant expose les réglages vidéo disponibles ; ils sont conservés pour les réglages manuels.

4. Audits et aide IA

  1. Lancez l’audit du PC ou du serveur depuis l’application Technicien pour relever les informations utiles au diagnostic.
  2. Exportez le bilan si vous devez le conserver ou le transmettre. Les filtres de confidentialité réduisent les informations identifiantes selon le type d’export.
  3. L’aide IA est facultative. Configurez séparément Analyste, Reviewer et Arbiter : fournisseur, connexion, modèle et effort disponible. Les clés API personnelles sont possibles ; choisissez le filtre de confidentialité avant l’envoi. Les étapes suivantes complètent et critiquent les résultats précédents sans relancer tous les tests.
  4. Le Technicien vérifie les recommandations et réalise les réparations. L’application ne génère pas de script BAT de correction.

5. Console d’administration

Utilisateurs et Techniciens

Créez les comptes, attribuez les droits et limitez les groupes visibles dans le carnet de chaque Technicien.

Ordinateurs et audits

Consultez les postes inscrits, leurs caractéristiques et les résultats d’audit. Exportez un inventaire pour préparer un suivi.

Outils techniciens

Préparez des outils qui peuvent être distribués aux Techniciens selon les autorisations du serveur.

Personnalisation et licence

Ajoutez le nom de votre société et votre logo. La licence multi-Techniciens règle le nombre de comptes Technicien autorisés.

Options des onglets du serveur

Les options affichées dépendent du rôle connecté et des droits accordés.

Vue d’ensemble

Consultez l’état du service, les versions et les indicateurs de fonctionnement avant une intervention d’administration.

Utilisateurs

Créez et gérez les comptes d’administration. Le compte admin sert à gérer le serveur ; il ne prend pas de sessions de contrôle à distance.

Techniciens

Créez les comptes Technicien, gérez leur état et leurs autorisations. Une licence multi-Techniciens règle le nombre de comptes habilités. Les postes associés aux comptes sont soumis aux contrôles de licence.

Ordinateurs

Consultez les appareils inscrits, leurs noms, versions et caractéristiques. Les audits PC et codec examinent les postes et guident le choix automatique. Exportez un inventaire pour le suivi autorisé.

Journaux

Recherchez les événements du service, filtrez la période et le niveau, puis exportez les éléments utiles au dépannage. Évitez de transmettre des secrets ou des données personnelles inutiles.

Erreurs

Consultez les rapports de panne et leurs informations associées, puis exportez un diagnostic. L’aide IA oriente la réparation ; le Technicien applique et vérifie les actions manuellement.

Outils techniciens

Classez les utilitaires dans des dossiers et partagez la bibliothèque entre les Techniciens. Envoyez un outil au Client depuis la session distante. Vérifiez sa provenance avant déploiement.

Paramètres

Réglez l’adresse et les paramètres de connexion du serveur, la sécurité et les préférences proposées. Après un changement réseau, vérifiez DNS, certificat et paramètres remis aux applications Windows.

Personnalisation

Renseignez le nom de votre société et ajoutez votre logo pour personnaliser l’interface.

Licence

Consultez l’état et les quotas de comptes Technicien et de postes. Le mode gratuit inclut un compte Technicien de prise en main, en plus du compte admin d’administration.

Langues

Gérez les langues proposées lorsque cette rubrique est disponible pour votre compte.

Sauvegarde / Restauration

Créez une archive complète chiffrée par mot de passe, enregistrez-la hors du NAS et restaurez-la depuis la console ou l’assistant DSM. Une restauration remplace l’état présent : vérifiez archive et mot de passe avant confirmation.

6. Installer le serveur sur Synology

  1. Vérifiez DSM 7.2.2-72806 minimum et la compatibilité du modèle dans le Centre de paquets.
  2. Installez le SPK TGME Remote depuis le Centre de paquets, puis ouvrez la console du NAS.
  3. Terminez la configuration initiale du compte admin et suivez les étapes de protection affichées.
  4. Pour les connexions depuis Internet, suivez le guide réseau : TCP 5081, TCP/UDP 3478 et UDP 50000–51000. TCP 5080 reste interne et ne doit pas être redirigé vers Internet.
  5. Téléchargez ensuite les applications Client et Technicien depuis la console.

7. Sauvegarde et restauration

Utilisez les fonctions de sauvegarde de la console pour conserver la configuration du serveur dans une archive protégée par mot de passe. Gardez une copie hors du NAS, dans un emplacement maîtrisé.

Après une panne ou un remplacement du NAS, réinstallez le paquet compatible puis restaurez l’archive depuis la console ou le parcours de restauration DSM prévu. Les postes Clients déjà inscrits peuvent se reconnecter au serveur restauré si son adresse et sa configuration correspondent.

La sauvegarde du NAS ne sauvegarde pas les fichiers des ordinateurs dépannés. Conservez aussi les copies nécessaires des éléments administratifs et de l’archive de restauration.

8. Mises à jour

Installez le paquet serveur depuis DSM ou la procédure de mise à jour validée par l’administrateur. Téléchargez les versions Client et Technicien depuis la console du NAS afin de garder les postes sur une version compatible avec le serveur.

Avant une opération majeure, conservez une sauvegarde récente et vérifiez le résultat de mise à jour dans la console.

Pour les étapes détaillées d’installation et la liste complète des ports, consultez le guide Synology. Pour télécharger le paquet 0409, visitez la page de téléchargement.
